# Romer Casper — Modern Bento Portfolio

Responsive static portfolio with a modular bento layout, dark/light theme, expertise carousel, career section and Gmail draft form.

## Run
Extract the ZIP and open `index.html` in a browser, or deploy the entire folder to any static host (including GitHub Pages). No build step or backend is required. Google Fonts is optional; local system fonts are the fallback.

## Customize
- `index.html`: profile, career, expertise and contact information.
- `assets/css/style.css`: design tokens, layout and responsive styling.
- `assets/js/script.js`: theme persistence, mobile navigation, expertise carousel and Gmail draft creation.
- `assets/img/profile.jpg`: original profile image.
- `logo1.png`: original logo.
- `screenshot1.png`: archived screenshot of the original design, not the redesigned website.

The contact form opens a prefilled Gmail draft; it does not automatically send email. The visitor must review and send the message in Gmail.
